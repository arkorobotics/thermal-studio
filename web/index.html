How to update (about 2 minutes)
  1. Close Thermal Studio and any other camera app.
  2. On the PureThermal, hold BOOT, press and release RST, then release BOOT. The LED goes dim and stops blinking.
  3. Download from the firmware releases page and double-click it in Downloads to unpack it.
  4. Install dfu-util (brew install dfu-util) and run:
  5. Unplug the PureThermal, wait 5 seconds, and plug it back in. Flashing restarts the board but not the Lepton sensor; without a full power cycle the camera connects but sends no video.
  6. Reopen Thermal Studio. Info should show the new board firmware.

The bootloader is in ROM, so a failed flash can always be retried. Full instructions
